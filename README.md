# Проект "Ходячий" - Моделирование движения людей

## Класс Human

**Что делает:** Создает объект "человек" с возможностью случайного перемещения.

**Основные функции:**
- Хранит данные: ФИО, возраст, скорость, координаты
- Метод `move()` - перемещает человека по модели Random Walk
- Геттеры/сеттеры для доступа к данным
- Автоматически корректирует скорость при движении

## Функция main()

**Что делает:** Запускает симуляцию движения группы людей.

**Процесс:**
1. Создает массив людей (10 человек)
2. Задает время симуляции (10 секунд)
3. В цикле заставляет каждого человека двигаться
4. Выводит начальные, промежуточные и финальные позиции
5. Показывает статистику пройденных расстояний

## Модель движения Random Walk

**Формулы:**

```
Направление: θ = случайное(0, 2π)
Длина шага: L = скорость × случайное(0.5, 1.5)
Новые координаты:
  x = x + L × cos(θ)
  y = y + L × sin(θ)
Новая скорость: скорость = скорость × случайное(0.8, 1.2)
```

**Принцип:** Каждый шаг - случайное направление и длина, что создает естественную траекторию "блуждания".

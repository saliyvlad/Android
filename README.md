# Проект "Ходячий" - Моделирование движения

## Классы

### Human - Пешеход
**Что делает:** Создает человека со случайным движением.
- **Движение:** Random Walk (случайные направления)
- **Свойства:** ФИО, возраст, скорость, координаты
- **Методы:** move(), геттеры/сеттеры

### Driver - Водитель (наследник Human)
**Что делает:** Создает водителя с прямолинейным движением.
- **Движение:** Прямолинейное с небольшими отклонениями
- **Дополнительно:** тип транспорта, направление
- **Переопределен:** метод move()

## Главная функция main()

**Что делает:** Параллельная симуляция движения.
```kotlin
// Создает 4 пешеходов и 1 водителя
// Запускает каждого в отдельном потоке
// Выводит позиции каждую секунду
// Показывает финальную статистику
```

## Модели движения

### Human - Random Walk
```
θ = случайное(0, 2π)           // направление
L = скорость × случайное(0.5, 1.5)  // длина шага
x = x + L × cos(θ)
y = y + L × sin(θ)
```

### Driver - Прямолинейное
```
θ = θ + случайное(-0.17, 0.17)  // ±10° отклонение
x = x + скорость × cos(θ)
y = y + скорость × sin(θ)
```

## Особенности
- **Многопоточность:** Каждый объект в отдельном потоке
- **Наследование:** Driver расширяет Human
- **Полиморфизм:** Разное поведение move()
- **Параллелизм:** Все движутся одновременно

**Результат:** Пешеходы блуждают случайно, водитель едет прямо - все одновременно!
